# VideoTV 直达播 — 企业级直播解决方案

[![Website](https://img.shields.io/badge/官网-videotvai.com-blue)](https://videotvai.com)

**VideoTV**（直达播）是一家专注于企业级直播技术服务商，核心覆盖三大场景：

- 🏥 **医疗学术会议直播** — 30+场三甲医院/省级学会直播经验
- 🛒 **私域电商直播** — 从0到1搭建企业直播带货体系
- 🔬 **手术示教直播** — 手术室级别的低延迟示教方案

## 技术栈

- 基于 **腾讯云TRTC** 实时音视频能力
- 集成 **保利威** 企业级视频云
- 纯静态HTML架构，Nginx/CDN加速部署

## 核心能力

| 场景 | 解决方案 | 特色 |
|------|---------|------|
| 医疗学术会议 | 多机位导播+PPT同步+回放 | 等保三级合规，支持白名单加密 |
| 私域电商 | 小程序/H5直播+带货插件 | 低延迟互动，支持uniapp集成 |
| 手术示教 | 手术室级高清直播+录制 | 医疗级设备适配，实时标注 |
