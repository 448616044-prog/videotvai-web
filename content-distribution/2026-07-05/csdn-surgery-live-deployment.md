## 一、需求背景

最近帮一家三甲医院落地了一套私有化手术直播系统。需求很明确：

1. 手术室画面实时传输到示教室（同楼不同楼层）
2. 支持多地专家远程观看（不能走公网直播平台）
3. 所有手术视频数据不出院内网
4. 支持录制、回放、权限管理

院方原来咨询的几家SaaS厂商报价都在20-50万/年。最后我们用私有化方案搞定，首年硬件+软件不到10万。

这篇文章记录完整的架构设计和实施过程。

## 二、系统架构设计

### 2.1 总体架构

```
手术室（推流端）
    ↓ NDI/RTMP
院内机房（流媒体服务器）
    ↓ HLS/WebRTC
示教室/科室终端（观看端）
    ↓ VPN
院外专家（远程观看）
```

核心思路：**流媒体服务器部署在医院机房，所有视频流转发都在内网完成，不经过任何第三方云**。

### 2.2 推流端选型

手术室端需要采集以下信号源：
- 术野摄像头（索尼/奥林巴斯医用摄像机，SDI输出）
- 全景摄像头（观察手术室整体情况）
- PACS/DICOM影像（CT/MRI图像）
- 生命体征监护仪画面

推流设备选型对比：

| 设备 | 价格 | 输入接口 | 适用场景 |
|------|------|----------|----------|
| Kiloview E2 | ¥4000 | 1路SDI/HDMI | 单摄像头推流 |
| Magewell Ultra Stream | ¥8000 | 1路HDMI+1路SDI | 双画面 |
| 定制工控机 | ¥15000 | 4路SDI采集卡 | 多画面手术室 |

我们选的是Kiloview E2，性价比最高。SDI输入接术野摄像头，推RTMP流到服务器。

### 2.3 流媒体服务器

硬件配置：
- 2U机架式服务器
- CPU: Intel Xeon Silver 4210 × 2
- 内存: 128GB DDR4
- 存储: 4TB SSD（RAID5）
- 网络: 万兆光口 × 2

软件栈：
```
Nginx-RTMP (收流/转推)
    ↕
SRS/MediaServer (转码/录制)
    ↕
Node.js 后端 (权限管理/API)
    ↕
Vue.js 前端 (观看页面)
```

为什么不用云服务？因为医院要求数据不出院区。用阿里云/腾讯云的直播服务意味着视频流要先上传到云端再分发下来，这个延迟和合规问题无法接受。

### 2.4 观看端

观看端不需要安装任何客户端，浏览器直接打开内网地址即可观看。技术方案：

- **内网观看**：HLS协议，延迟3-5秒
- **院外专家**：通过医院VPN接入内网后观看
- **移动端**：手机/平板同样浏览器观看，自适应码率

## 三、关键技术细节

### 3.1 低延迟优化

手术示教对实时性要求极高，术者操作和示教室看到画面之间的延迟不能超过1秒。

优化措施：
1. 推流端使用NDI协议（延迟<100ms），而非RTMP（延迟1-3秒）
2. 服务器端不做转码，直接透传
3. 播放端使用WebRTC拉流，延迟<500ms
4. 网络QoS策略：手术室到机房网络优先级最高

### 3.2 录制与回放

```python
# 自动录制配置（SRS）
vhost __defaultVhost__ {
    dvr {
        enabled on;
        dvr_path /data/recordings/[app]/[stream]/[date]/[hour]-[minute].mp4;
        dvr_plan segment;
        dvr_duration 60; # 每60分钟切一片
        dvr_wait_keyframe on;
    }
}
```

录制文件按日期和手术室自动归档，保留90天。超期自动删除。

### 3.3 权限管理

四层权限体系：

1. **手术级别**：公开示教 vs 内部研讨 vs 专家会诊
2. **科室权限**：本科室手术只有本科室医生可以观看
3. **个人权限**：规培生/住院医/主治/主任，不同级别看到的内容不同
4. **设备白名单**：只有医院注册设备可以访问直播流

所有权限通过JWT Token + ACL控制，与医院HIS系统对接。

## 五、踩过的坑

1. **SDI转网络延迟**：最初用普通采集卡，延迟600ms；换成Kiloview编码器后降到80ms
2. **示教室大屏适配**：手术画面是16:9，但示教室大屏是超宽屏。需要做画面裁剪和拼接
3. **并发瓶颈**：一台服务器理论承载200路并发；但录制+转码会消耗大量CPU，实际建议不超过50路并发
4. **网络安全**：最初想直接在防火墙上开端口让院外观看，被信息科否决。后来用VPN方案才通过安全审查

## 六、总结

对于年手术直播50场以上的医院，私有化部署的综合优势远大于SaaS：

- 数据安全：视频不出院区，满足等保要求
- 成本优势：3年仅为SaaS的1/4
- 灵活定制：对接HIS、PACS等院内系统
- 长期可控：不存在供应商涨价/停服风险
